# Scroll — прототип Telegram Mini App (рабочее название)

Лента коротких видео из Telegram-каналов (как TikTok), каталог каналов, новости, профиль.

- `src/` — само приложение (React + Vite)
- `src/lib/reco.js` — рекомендации: сначала популярное, потом под интересы человека
- `src/lib/store.js` — лайки, сохранённое, подписки, сколько досмотрел
- `api/feed.js` — берёт свежие посты с публичных страниц каналов t.me/s/...
- `api/channels.js` — список каналов (страна, категория)

Прототип: данные человека пока хранятся на телефоне, лента собирается «на лету».
